## 作品一：贵妃焕新颜 · HBN 古风互动 H5 小游戏

- **品牌 / 产品**：HBN 护肤品（α-熊果苷焕颜精华水）
- **形式**：手机竖屏互动 H5 小游戏，扫码即玩
- **视觉**：自己设计的 11 张古风插画页面（Q 版唐风贵妃、水墨纸色、朱红印章按钮）
- **故事与玩法**：
  - 子时贵妃熬夜吃荔枝，第二天照镜子发现皮肤暗沉粗糙，陛下又即刻召见。玩家要在托盘上为贵妃挑一样焕颜之物。
  - 选铅粉：微量毒性导致敏感肌，挑战失败。
  - 选普通护肤水：皮肤依旧暗沉，挑战失败。
  - 选 HBN：“此乃神颜！”，挑战成功，圣心大悦。
  - 结尾页“寸刻呵护 肌肤无忧”，可以再次挑战，也可以点击种草跳转购买。
- **传播策略**：游戏化的“错误选项对比”突出产品功效；古风宫廷题材贴合国潮审美；结尾页直接转化到购买
- **技术实现**：
  - 动效：分镜逐格入场、水墨扩散转场、印章呼吸按钮、人物动作、文字逐行书写、花瓣与闪光
  - 音乐：代码合成的古筝与箫背景音乐（无版权问题），以及点击、成功、失败音效
- **线上地址**：https://suxiao693686-create.github.io/coze-hot/hbn-h5/
- **二维码**：`hbn-h5/qrcode-poster.png`（海报版）、`hbn-h5/qrcode.png`（纯二维码），静态二维码不会过期
- **待定**：“点击种草”目前跳转京东“HBN官方旗舰店”搜索页，可换成指定的官网或商品链接

## 作品二：油纸伞 · 非遗文化主题网站

- **主题**：非物质文化遗产「油纸伞」的传承与创新，主视觉为“一竹一纸一桐油，半生半世半浮华”
- **形式**：5 个页面的网站，顶部导航可以互相跳转
  - 首页：油纸伞主视觉 banner
  - 介绍：知起源（起源、宋代、唐代时间线）、知寓意（遮风避雨、五子登科等 7 个寓意）
  - 制作流程：伞的结构图（长伞骨、短伞骨、竹跳、伞面、伞柄）、制作步骤（制伞骨 → 制伞面 → 定型 → 绘制 → 刷桐油 → 晾晒）、成伞大赏轮播
  - 保护创新：国家非遗保护、文旅创新、服务创新，以及大数据分析、智能化反馈、口碑 / 事件 / 品牌营销
  - IP 形象：原创 IP「伞小桐」，包括人设卡、主题色、三视图、设计细节（甲路油纸伞伞骨裙摆、新中式发型、筷子发簪、旗袍）、6 个 Q 版表情包
- **视觉**：全部图片在 Photoshop 中设计，宣纸底纹配古画人物、朱红印章与毛笔字
- **技术实现**：HTML + CSS + JavaScript，带悬停动效、步骤高亮和成伞轮播
- **线上地址**：https://suxiao693686-create.github.io/coze-hot/youzhisan/
- **二维码**：`youzhisan/qrcode-poster.png`（海报版）、`youzhisan/qrcode.png`（纯二维码），静态二维码不会过期
- **待补**：保护创新页的整页背景图 `images/8.png`
