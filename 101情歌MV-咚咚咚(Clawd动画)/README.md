# 101 情歌 MV《咚咚咚》（Clawd 手绘动画风格）

用 [JohnHeibel/ClaudeAnimationBase](https://github.com/JohnHeibel/ClaudeAnimationBase) 的手绘动画风格（p5.js + p5.brush 水彩笔刷、线条抖动 boil、纯 2D、画出来的转身、每个镜头都有事件、镜头之间都有转场）做的一支 60 秒情歌 MV。**词、曲、编曲、演唱（合成人声）、画面全部由代码生成**，没有用任何外部素材。

成片：`out/dongdong_mv.mp4`（1920×1080，24fps，60 秒）

## 故事

Clawd 喜欢住在街对面窗户里的 Blu，可是他不敢开口，于是抱起台灯，把自己的心跳一下一下闪到对面。她听见了，也闪了回来。

|---|---|---|---|
| 0–9.6 | 前奏 | — | 夜街，对面窗户亮灯，Blu 冒出来哼歌；镜头摇到 Clawd，心跳鼓点进来，他一见钟情 |
| 9.6–19.2 | 主歌 1 | 隔着一条街的窗 / 亮着你的微光 | Clawd 趴在窗口望着远处的她，挥手，她一转头，他吓得缩到窗台下，只露出一双眼 |

## 声画一致：一张时间表驱动一切

`music/song.py` 生成音乐的同时，还会导出 `src/song_data.js`，里面是每一下底鼓、拍手和每一个歌词字的精确时间。画面里所有跟节奏有关的东西都从这张表里读时间：

- **底鼓 = 心跳**：前奏和主歌是“咚-咚”双击心跳，副歌是四拍底鼓。胸口的心、台灯、光束、街灯、彩灯和镜头冲击都在鼓点上动。
- **每个“咚”**：一次大闪光，加一圈扩散的光环。
- **“一闪一闪”**：四个字，光束对着她的窗闪四下。
- **“我喜欢你”**：每唱一个字，光之心跳一下。
- **“就在今晚”**：彩灯从中间往两边一颗颗亮起。
- **八音盒**：每个音符点亮一颗不同的星星。
- **卡拉 OK 字幕**：每个字在被唱出的那一帧变色、弹跳，“咚”是金色。

## 音乐

- 100 BPM，C 大调，前奏 C–Am–F–G，主歌 C–Am–F–G ×2，副歌 F–G–Em–Am–F–G–C–C。
- 乐器全部用 numpy 合成：底鼓、拍手、踩镲、军鼓滚奏、锯齿贝斯、FM 电钢琴、铺底、八音盒、噪声上扬。底鼓对和声做侧链压缩，所以整首歌跟着“心跳”一起泵动。
- 人声用共振峰合成：pypinyin 把每个字拆成声母和韵母，声母用噪声或爆破合成，韵母是一条在 4 个共振峰之间滑动的元音轨迹，再加上滑音和颤音。这是机器味的“虚拟歌手”声线，不是真人演唱。

## 怎么运行

需要 Node.js、Chrome/Chromium、ffmpeg 和 Python 3（numpy、scipy、pypinyin）。

```bash
npm install
pip install numpy scipy pypinyin
python3 music/song.py                        # → assets/song.wav / song.mp3 + src/song_data.js
node render.mjs --clip --out=out/video.mp4   # 有显卡的机器直接渲染
# 没有显卡（云容器）：软件 WebGL + 2/3 像素密度，4 个进程并行
./r.sh --frames --range=0:15 & ./r.sh --frames --range=15:30 & ./r.sh --frames --range=30:45 & ./r.sh --frames --range=45:60 & wait
node render.mjs --encode --audio=assets/song.mp3 --out=out/dongdong_mv.mp4
```

用 Chrome 打开 `studio.html` 可以拖动时间轴逐帧看（`?t=43.2` 直接跳到“我喜欢你”）。

## 文件

| 路径 | 内容 |
|---|---|
| `STORYBOARD.md` | 分镜：每个镜头的事件、阅读顺序和转场 |
| `music/song.py` | 作词、作曲、编曲、合成演唱、混音 |
| `src/song_data.js` | 自动生成的节拍和歌词时间表 |
| `src/scenes/dongdong.js` | MV 的全部镜头 |
| `src/core.js` `src/clawd.js` `src/timeline.js` | ClaudeAnimationBase 引擎（MIT 协议，见 `LICENSE`）。改了两处：支持 `?pd=` 像素密度，以及预加载中文字幕字体 |
| `render.mjs` / `r.sh` | 渲染器；`--soft-gl` 加了两个开关，修复无显卡时水彩填充每笔要 2 秒的问题 |
