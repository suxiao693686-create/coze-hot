# 101 歌词MV生成器（素颜片段）

用代码把**歌曲音频 + LRC 歌词**合成一段卡拉OK风格的 MV：歌词逐字跟着时间轴高亮，适合做「许嵩 - 素颜」这类歌曲的片段视频。

![效果预览](效果预览.png)

## 效果
- 逐字卡拉OK填色（白字 → 粉色），按 LRC 时间自动匹配
- 当前句放大居中，上一句 / 下一句淡显，换句时柔和滑动
- 「素颜」风格的粉蓝渐变背景 + 漂浮光斑，光斑会跟着音乐响度呼吸
- 也可以用自己的图片做背景（缓慢推拉 + 交叉淡化）
- 片头歌名 / 歌手，底部进度条，首尾音画淡入淡出
- 支持只截取某一段（`--start` / `--end`），默认竖屏 1080x1920，适合抖音

## 准备素材
1. **音频**：`素颜.mp3`（用你自己有版权 / 已购买的音源）
2. **LRC 歌词**：在 QQ音乐、网易云等平台下载这首歌的 `.lrc` 文件，格式类似：
   ```
   [01:02.35]第一句歌词
   [01:05.80]第二句歌词
   ```
   本目录的 `示例歌词.lrc` 只用来演示格式，内容是占位文字。
3. （可选）背景图：把几张图放进一个文件夹，比如 `bg/`

## 运行
```bash
pip install pillow numpy      # 还需要装好 ffmpeg

# 截取 1分02秒 ~ 1分40秒 这段做 MV
python3 lyric_mv.py --audio 素颜.mp3 --lrc 素颜.lrc \
    --start 62 --end 100 \
    --title 素颜 --artist 许嵩 \
    --out suyan_mv.mp4

# 用自己的背景图 + 横屏
python3 lyric_mv.py --audio 素颜.mp3 --lrc 素颜.lrc --start 62 --end 100 \
    --bg ./bg --size 1920x1080 --out suyan_mv_h.mp4
```

| 参数 | 说明 |
| --- | --- |
| `--audio` | 音频文件（mp3/wav/flac/m4a） |
| `--lrc` | LRC 歌词文件，支持 `[offset:]` 和一行多个时间戳 |
| `--start` / `--end` | 片段起止秒数（不填就是整首） |
| `--title` / `--artist` | 片头文字 |
| `--bg` | 背景图片目录，不填使用渐变 + 光斑 |
| `--size` | `1080x1920`（竖屏）或 `1920x1080`（横屏） |
| `--fps` | 帧率，默认 30 |
| `--font` | 自定义中文字体（找不到系统中文字体时指定） |

## 小技巧
- 歌词整体快了或慢了：在 LRC 里加 `[offset:300]`（单位毫秒，正数表示歌词往前提）
- 想改颜色：修改 `lyric_mv.py` 顶部的 `PALETTE_*` 和 `TEXT_HIGHLIGHT`
- 渲染速度大约每秒视频 3~4 秒，40 秒的片段 2~3 分钟出片
