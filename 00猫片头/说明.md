# 00猫塑料小课堂 · 片头

- `00猫片头.mp4`：成品，抖音竖屏 1080×1920，约 6 秒，带音乐、音效、配音、字幕
- 配音：Kokoro 离线中文配音 23 号音色（`tts.py` 第 4 个参数可以换音色编号）
- `intro.html`：动画本体。用浏览器打开可以直接预览
- 每期换课程标题：改 `intro.html` 顶部 `CONFIG` 里的 `lessonNo` / `lessonTitle`，再运行 `bash build.sh`

## 时间线
| 时间 | 画面 |
|---|---|
| 0 ~ 0.95 秒 | 合着的模具前，00猫眯着眼舔爪子，俏皮的踮脚音乐 |
| 1.0 ~ 1.45 秒 | 头上冒出"！"，喊"喵喵！" |
| 1.45 ~ 2.05 秒 | 起跳抓住链条，用力往下拉，喊"开模！"，音乐蓄力 |
| 2.05 ~ 2.75 秒 | "咚"！模具左右分开，冒蒸汽，塑料粒子喷出来，欢快音乐进入 |
| 2.45 ~ 4.75 秒 | 卡着鼓点依次弹出"00猫 / 塑料小课堂 / 开课啦！"，00猫跟着节拍跳、挥手，配音念标题 |
| 4.75 ~ 5.35 秒 | 一大片彩色粒子从上往下倾泻，完成转场 |
| 5.05 ~ 6.2 秒 | 本期课程卡：第01课 · 什么是改性塑料？ |
