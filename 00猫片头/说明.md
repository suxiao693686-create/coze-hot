# 00猫塑料小课堂 · 片头

- `00猫片头.mp4`：成品，抖音竖屏 1080×1920，约 6 秒，带音乐、音效、配音、字幕
- `intro.html`：动画本体。用浏览器打开可以直接预览
- 每期换课程标题：改 `intro.html` 顶部 `CONFIG` 里的 `lessonNo` / `lessonTitle`，再运行 `bash build.sh`

## 时间线
| 时间 | 画面 |
|---|---|
| 0 ~ 1.1 秒 | 合着的模具前，00猫眯着眼舔爪子 |
| 1.1 ~ 1.75 秒 | 头上冒出"！"，蹲下起跳，抓住链条把手 |
| 1.75 ~ 2.05 秒 | 用力往下拉，喊"开模！" |
| 2.05 ~ 2.75 秒 | 模具左右分开，冒蒸汽，塑料粒子喷出来 |
| 2.6 ~ 4.75 秒 | 弹出"00猫 / 塑料小课堂 / 开课啦！"，00猫跟着节拍跳、挥手，配音念标题 |
| 4.75 ~ 5.35 秒 | 一大片彩色粒子从上往下倾泻，完成转场 |
| 5.05 ~ 6.2 秒 | 本期课程卡：第01课 · 什么是改性塑料？ |
