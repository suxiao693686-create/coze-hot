# 贵妃焕新颜 · HBN 古风互动 H5

一个手机竖屏 H5 小游戏：封面 → 加载 → 剧情漫画 → 游戏规则 → 选择（铅粉 / 普通护肤水 / HBN）→ 失败或成功 → 结尾页。在结尾页点「点击种草」会跳转到购买页。

- **动效**：分镜逐格入场，按钮呼吸、印章落下，人物摇摆或抽泣，文字逐行“书写”出现，水墨扩散式转场，还有花瓣和闪光
- **音乐**：背景音乐是代码合成的古筝、箫、碰铃（D 宫五声调式，可无缝循环，无版权问题），点击、成功、失败各有音效；右上角 ♪ 按钮可以开关音乐
- **适配**：适配各种手机屏幕，图片不会被裁切；在微信内打开时尝试自动播放音乐

### 开启 GitHub Pages（只需一次）

1. 把这个分支合并到 `main`，或者直接用当前分支
2. 打开仓库 **Settings → Pages**
3. Source 选 **Deploy from a branch**，Branch 选 `main`（或当前分支），目录选 `/ (root)`，然后保存
4. 等 1～2 分钟，用浏览器打开上面的网址确认能访问，再扫码测试

仓库根目录的 `.nojekyll` 用来让 Pages 直接发布静态文件，请不要删除。

> 国内部分网络访问 github.io 会比较慢，偶尔打不开。如果展示时需要更稳定的访问，可以把整个 `hbn-h5` 文件夹上传到任意静态托管（例如腾讯云 COS、阿里云 OSS 的静态网站功能），然后运行 `python3 tools/make_qr.py 新网址` 重新生成二维码。

## 修改

| 想改什么 | 改哪里 |
| --- | --- |
| 「点击种草」跳转链接 | `index.html` 里的 `CONFIG.buyUrl` |
| 背景音乐 | 替换 `assets/bgm.mp3`，或修改 `tools/make_music.py` 后重新运行 |
| 每页的动画和时间 | `main.js` 中的场景定义 `S`，以及 `style.css` |
| 设计稿图片 | 替换 `tools/source/*.jpg` 后运行 `python3 tools/build_assets.py` |

注意：在微信里不能直接打开淘宝、天猫的链接。如果跳转链接是淘宝或天猫，页面会提示用户「在浏览器打开」；京东链接和普通官网链接可以直接打开。

## 本地预览

```bash
cd hbn-h5
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000 ，用开发者工具切换到手机模式
```
